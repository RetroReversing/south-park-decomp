# Provenance

This checkpoint comes from the local RetroReversing South Park decompdecomp project. AI agents and local automated tools produced candidate C; sources in `src/` were accepted by the app's byte-for-byte checker. `best/` contains unfinished, unverified drafts. Saved notes record working hypotheses, not established facts. No model or source-access attribution beyond the saved evidence is inferred.

The checkpoint includes 32 previously missing matches recovered by rechecking preserved C with per-function compiler settings. The repository preserves these settings so import can reproduce the comparisons.
