# Working on this saved project

- Open this repository with decompdecomp's Open a saved project flow and supply your own supported ROM.
- Preserve function addresses, target bytes, compiler settings and existing verified sources.
- Use the ordinary byte-for-byte judge; never mark a match solely because metadata says it matches.
- Keep successful per-function compiler overrides in decompdecomp.json with the saved source.
- Keep unfinished drafts in best/. Names and types are provisional.
- Do not commit ROMs, extracted assets, generated original assembly, compilers, databases, credentials or build output.
- Do not download game data. Obtain user acceptance before proprietary compiler installations.
